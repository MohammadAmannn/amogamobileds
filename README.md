# Amoga Design System & Mobile App

A cross-platform React Native / Expo application featuring:
- **Native Mobile App** (Android APK & iOS)
- **Web Design System Playground** (Desktop simulator, device frame, code preview)

The project source code is located in [`amogamobileds-v1/`](./amogamobileds-v1).

## Quick Start

```bash
cd amogamobileds-v1
npm install

# Run on Web (Design System Playground)
npm run web

# Run on Android
npm run android

# Run on iOS
npm run ios
```

For complete architectural documentation, how web and mobile are separated, how routing works, and step-by-step guides on adding new features safely, see:
📖 **[Full Documentation in amogamobileds-v1/README.md](./amogamobileds-v1/README.md)**
